### 4.1 起票の進め方（2026-11-07 確定）

school-timetable の台帳は Task を1件ずつしか開けない。続きのセッションで確かめた時点（統合ブランチ `ba73531`）では、別の Task `v5-per-school-plan-mode-design`（設計だけ・11/7 21:55 JST 起票）が `builder_working` + `codex` で進行中だった。また school-timetable は GitHub Issue を使っていない。そこで荒木に確かめた。

- 問い「引き継ぎ §4 の6件をどう扱いますか？」→ 回答（原文）：「空いてから1件ずつ (Recommended)」。台帳が `idle` に戻ってから、先方の運用どおり1件ずつ起票する。それまでは台帳に何も書かない。
- 問い「school-timetable で最初に起票する Task はどれにしますか？」→ 回答（原文）：「⑥ JWT_SECRET の既定値 (Recommended)」。

起票するときの注意：
- ⑥ は「未設定なら起動を止める」形に直す想定。本番の env に `JWT_SECRET` が入っていないと、反映した時点で v5 が起動しなくなる。本番の設定の読み取りは、先方の運用ではユーザーの1回ごとの許可が要る（Builder の手番には含めない）。
- ④ は v5 の完成確認と v4 の切り替えの後（先方の最優先ルール）。② の切り替えスイッチと ⑤ は、school-manage の共通基盤（#4〜#6）ができるまで動かせない。
