## 3. 進め方の変更点（2026-11-07 確定）

`docs/WORKFLOW.md` と DESIGN-INTEGRATION §9（進め方4）では **Builder＝Cursor** と決めた。次のセッションからは **Muse と swarmchat でやり取りしながら進める**とのことなので、次の2点を最初に確かめて `docs/WORKFLOW.md` を直すこと。

- Claude の役割と、swarmchat での受け渡しの形。Issue と PR はそのまま使うか。→ **Issue と PR が正本。swarmchat は連絡だけ**（荒木の回答）。Claude の役割（起票とレビュー）は変えない。

`docs/WORKFLOW.md`・`AGENTS.md`・DESIGN-INTEGRATION §9 を直した。

前のセッションにも続きのセッション（クラウド）にも swarmchat への接続が無く、swarmchat には何も送っていない。
